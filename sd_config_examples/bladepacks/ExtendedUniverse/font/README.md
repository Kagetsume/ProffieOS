# Per-preset font overlays

Copy each subfolder to the **SD card root** as `font/<PresetName>/` (same path as `font_overlay=` in `config/presets.ini`).

WAVs here override matching files from the primary `font=` directory on the SD card. Typical overrides: **`name.wav`**, `in/`, `out/`, `clash/`, or root `font.wav`.

Each preset has a matching subfolder here. Folders that only contain `.gitkeep` are placeholders until you add WAVs. Ahsoka's two looks are `font/AhsokaPadawan/` and `font/AhsokaWhite/`. Morgan Elsbeth's Blade of Talzin is `font/MorganElsbeth/`. Revan's two blades are `font/RevanPurple/` and `font/RevanRed/`. Starkiller is `font/Starkiller/`. Baylan Skoll is `font/BaylanSkoll/`.
