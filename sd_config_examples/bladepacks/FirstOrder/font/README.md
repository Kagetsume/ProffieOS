# Per-preset font overlays

Copy each subfolder to the SD root as `font/<PresetName>/` to match `font_overlay=` in `config/presets.ini`.

Override **`name.wav`**, `in/`, `out/`, `clash/`, hum, or root `font.wav` from your primary `font=` pack. **`KyloRen/`** and **`Rey/`** each contain a `font.wav` voice prompt.
