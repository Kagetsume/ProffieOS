# Per-preset font overlays

Copy each subfolder to the **SD card root** as `font/<PresetName>/` (same path as `font_overlay=` in `config/presets.ini`).

WAVs here override matching files from the primary `font=` directory on the SD card (`SmthJedi/` when `font = SmthJedi`). Typical overrides: character-specific `in/`, `out/`, `clash/`, or a root `font.wav`.

Folders are empty in the repo until you add sound files.
